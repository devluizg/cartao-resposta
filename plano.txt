  PROBLEMAS IDENTIFICADOS

  🔴 Críticos (Afetam 99% de confiabilidade)

  1. Iluminação Irregular (image_processing.py:7-53)
    - CLAHE com parâmetros fixos não se adapta a variações extremas
    - Threshold adaptativo falha com sombras/reflexos
    - Combinação Otsu + Adaptativo pode criar ruído em áreas escuras
  2. Detecção de Bolhas Frágil (image_processing.py:118-278)
    - HoughCircles sensível a qualidade da imagem (param1=50, param2=25)
    - Parâmetros de raio fixos (minRadius=10, maxRadius=30) não escalam
    - Fallback por contornos usa circularidade fixa (0.7) que falha com bolhas parcialmente marcadas
  3. Correção de Perspectiva Limitada (image_processing.py:55-116)
    - Depende de contorno externo nítido
    - Fallback para bounding box perde precisão

  🟡 Moderados (Afetam precisão)

  4. Clustering Rígido (image_processing.py:280-515)
    - DBSCAN com epsilon adaptativo, mas assume estrutura uniforme
    - Bolhas "sintéticas" mascaram problemas de detecção
    - Não valida alinhamento horizontal/vertical
  5. Análise de Preenchimento Simplista (analysis.py:8-82)
    - Fill rate baseado em área circular (80% raio)
    - Não distingue marcação forte vs sombra
    - Threshold adaptativo pode ser enganado por iluminação
  6. Falta de Validação Geométrica (analysis.py:124-341)
    - Segmentação de colunas frágil
    - Não valida proporções do cartão (ex: 297x210mm A4)

  1.1 Pré-processamento Adaptativo Multi-Camadas

  Arquivo: image_processing.py:7-53

  - Adicionar detecção automática de brilho global (histograma)
  - Criar perfis de pré-processamento (luz baixa, luz alta, mista)

  Pseudocódigo:
  def pre_processar_robusto(image):
      # 1. Converter para LAB e normalizar L channel
      lab = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
      l, a, b = cv2.split(lab)
      l_norm = cv2.normalize(l, None, 0, 255, cv2.NORM_MINMAX)

      # 2. Detectar perfil de iluminação
      hist = cv2.calcHist([l_norm], [0], None, [256], [0,256])
      brightness = np.mean(l_norm)
      contrast = np.std(l_norm)

      # 3. Aplicar CLAHE adaptativo
      if brightness < 100:  # Luz baixa
          clahe = cv2.createCLAHE(clipLimit=5.0, tileGridSize=(8,8))
      elif brightness > 180:  # Luz alta
          clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(16,16))
      else:  # Normal
          clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(12,12))

      # 4. Shadow removal (top-hat)
      kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (15,15))
      tophat = cv2.morphologyEx(l_norm, cv2.MORPH_TOPHAT, kernel)
      l_corrected = cv2.add(l_norm, tophat)

      # 5. Bilateral filter (preserva bordas)
      filtered = cv2.bilateralFilter(l_corrected, 9, 75, 75)

      # 6. Multi-threshold combinado
      binary_adaptive = cv2.adaptiveThreshold(...)
      binary_otsu = cv2.threshold(...)
      binary_local = cv2.threshold(..., cv2.THRESH_BINARY_INV + cv2.THRESH_TRIANGLE)

      # Combinar com pesos
      binary = cv2.addWeighted(binary_adaptive, 0.5, binary_otsu, 0.3, 0)
      binary = cv2.bitwise_or(binary, binary_local * 0.2)

      return binary, metadata

  def corrigir_perspectiva_robusto(image, binary):

      success, rect = detectar_por_contorno(binary)

      return aplicar_transformacao(image, rect)

  def detectar_bolhas_profissional(binary, image):
      h, w = binary.shape

      # Calcular escala da imagem (DPI estimado)
      escala = estimar_escala(binary)  # pixels por mm

      # Adaptar parâmetros de raio baseado na escala
      raio_esperado_mm = 3  # 3mm de diâmetro típico
      raio_px = int(raio_esperado_mm * escala)
      min_radius = int(raio_px * 0.7)
      max_radius = int(raio_px * 1.3)

      # Método 1: HoughCircles Adaptativo
      circles_hough = detectar_hough_adaptativo(binary, min_radius, max_radius)

      # Método 2: Template Matching
      template = criar_template_bolha(raio_px)
      circles_template = detectar_por_template(binary, template)

      # Método 3: MSER + Circularidade
      mser = cv2.MSER_create()
      regions = mser.detectRegions(binary)
      circles_mser = filtrar_regioes_circulares(regions, min_radius, max_radius)

      # Método 4: Contornos com features
      circles_contour = detectar_por_contorno_melhorado(binary)

      # Voting System: precisa 2+ métodos concordando
      bolhas_finais = aplicar_voting(
          [circles_hough, circles_template, circles_mser, circles_contour],
          threshold_distancia=raio_px * 0.3  # 30% do raio
      )

      # Validar com Hu Moments (invariante a rotação/escala)
      bolhas_validadas = []
      for bolha in bolhas_finais:
          moments = cv2.HuMoments(cv2.moments(extrair_roi(bolha)))
          if validar_circularidade_hu(moments):
              bolhas_validadas.append(bolha)

      return bolhas_validadas

  Pseudocódigo:
  def analisar_preenchimento_avancado(binary, bolha):
      cx, cy, r = bolha['x'], bolha['y'], bolha['radius']

      # ROI circular (atual)
      mask_circular = criar_mascara_circular(cx, cy, r * 0.8)
      roi_circular = cv2.bitwise_and(binary, mask_circular)

      # ROI retangular (validação cruzada)
      roi_rect = binary[cy-r:cy+r, cx-r:cx+r]

      # Métrica 1: Fill rate (atual)
      fill_rate_circular = cv2.countNonZero(roi_circular) / (np.pi * r**2)
      fill_rate_rect = cv2.countNonZero(roi_rect) / (roi_rect.size)

      # Métrica 2: Intensidade média
      intensidade_media = np.mean(roi_circular[roi_circular > 0])

      # Métrica 3: Gradiente (detecta bordas de marcação)
      gradiente = cv2.Sobel(roi_rect, cv2.CV_64F, 1, 1, ksize=3)
      energia_gradiente = np.sum(np.abs(gradiente))

      # Métrica 4: Textura (LBP - Local Binary Patterns)
      textura = calcular_lbp(roi_rect)
      uniformidade_textura = np.std(textura)

      # Métrica 5: Simetria radial
      simetria = calcular_simetria_radial(roi_circular, cx, cy, r)

      # Detector de anomalias
      is_sombra = detectar_sombra(roi_rect, gradiente)
      is_dobra = detectar_dobra(roi_rect, simetria)
      is_sujeira = detectar_sujeira(textura)

      # Classificação com pesos
      score = (
          fill_rate_circular * 0.4 +
          fill_rate_rect * 0.2 +
          (intensidade_media / 255) * 0.15 +
          (1 - uniformidade_textura) * 0.15 +
          simetria * 0.1
      )

      # Penalizar anomalias
      if is_sombra or is_dobra or is_sujeira:
          score *= 0.5
          confianca = 0.3
      else:
          confianca = min(abs(score - 0.5) * 2, 1.0)

      # Classificação final
      if score > 0.5:
          estado = "marcada"
      elif score > 0.2:
          estado = "parcial"
      else:
          estado = "vazia"

      return {
          'estado': estado,
          'score': score,
          'confianca': confianca,
          'metricas': {
              'fill_rate': fill_rate_circular,
              'intensidade': intensidade_media,
              'textura': uniformidade_textura,
              'simetria': simetria,
              'anomalias': [is_sombra, is_dobra, is_sujeira]
          }
      }

  FASE 3: Validação e Confiabilidade 🎯 Prioridade ALTA

  3.1 Validação Geométrica Rigorosa

  Arquivo: image_processing.py:280-515

  Ações:
  - Validar alinhamento horizontal (desvio padrão Y < 5% raio)
  - Validar espaçamento uniforme (CV < 15%)
  - Detectar outliers (Z-score > 2.5)
  - Implementar grid de referência esperado
  - Adicionar score de qualidade de detecção

  Pseudocódigo:
  def validar_geometria_questao(bolhas, num_alternativas=5):
      if len(bolhas) != num_alternativas:
          return False, 0.0, "Número de bolhas incorreto"

      # Validar alinhamento horizontal
      y_coords = [b['y'] for b in bolhas]
      y_std = np.std(y_coords)
      y_mean = np.mean(y_coords)
      raio_medio = np.mean([b['radius'] for b in bolhas])

      if y_std > raio_medio * 0.05:  # 5% do raio
          return False, 0.3, f"Desalinhamento vertical: {y_std:.1f}px"

      # Validar espaçamento uniforme
      x_coords = sorted([b['x'] for b in bolhas])
      espacos = np.diff(x_coords)
      cv_espacos = np.std(espacos) / np.mean(espacos)  # Coeficiente de variação

      if cv_espacos > 0.15:  # 15%
          return False, 0.4, f"Espaçamento irregular: CV={cv_espacos:.2f}"

      # Detectar outliers
      z_scores = np.abs(stats.zscore(x_coords))
      if np.any(z_scores > 2.5):
          outliers = np.where(z_scores > 2.5)[0]
          return False, 0.5, f"Outliers detectados: {outliers}"

      # Validar proporções
      largura_total = x_coords[-1] - x_coords[0]
      espaco_esperado = largura_total / (num_alternativas - 1)
      desvio_max = max([abs(espacos[i] - espaco_esperado) for i in range(len(espacos))])

      if desvio_max > raio_medio:
          return False, 0.6, f"Desvio de espaçamento: {desvio_max:.1f}px"

      # Calcular score de qualidade
      score = 1.0 - (y_std / raio_medio + cv_espacos + desvio_max / raio_medio) / 3

      return True, score, "OK"
